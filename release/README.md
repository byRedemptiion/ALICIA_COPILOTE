# Télécharger Alicia pour Windows

L’archive actuelle `Alicia-Windows-v0.3.zip` contient le projet et ses lanceurs Windows. Elle ne contient ni clé API, ni environnement Python, ni modèles préinstallés. La version précédente reste disponible dans ce dossier.

Après téléchargement :

1. Extraire complètement le ZIP.
2. Ouvrir le dossier Alicia et lancer `Installer_Alicia.bat` pour préparer les dépendances et télécharger les modèles gratuits.
3. Lancer `Lancer_Alicia.bat`.

La v0.3 démarre sur l’écran principal avec le microphone actif, utilise la voix neuronale Kokoro et la reconnaissance Whisper, et conserve un contexte court en mémoire. Stop coupe observation et écoute ; Reprendre relance. Fermer l’ancienne application avant de mettre ses dépendances à jour.

Le fichier `SHA256SUMS` permet de contrôler l’intégrité de l’archive. Les détails et limites de validation sont décrits dans le README du projet et dans `docs/VALIDATION_WINDOWS.md`.
