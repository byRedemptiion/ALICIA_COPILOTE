# Exemple de voix neuronale française

`voix-francaise.wav` a été généré réellement avec Kokoro, voix féminine française `ff_siwis`, vitesse `0.95`, sans API payante. Le fichier est un WAV mono PCM16 à 24 kHz, d’environ huit secondes.

Cet extrait permet d’écouter le timbre avant d’installer les modèles. Il ne s’agit ni d’un enregistrement du microphone, ni d’une voix clonée de ChatGPT. La lecture sur le PC Windows et l’appréciation du rendu restent à vérifier par l’utilisateur.
